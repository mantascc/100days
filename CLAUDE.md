# 100days — working rules

## Sketch-first
When asked to build something, default to a **daily sketch** in `daily-sketch/`
as a `sketch-<name>/` folder (an `index.html`, plus an `interface.md` so the
Imagination layer's `/inhale` can fold it back in). Do this unless explicitly
told otherwise. Sketch comes first, always.

## Never auto-create an indexed piece
The numbered `NN-name/` folders are the curated, indexed sketchbook. **Always
ask before creating a new indexed piece** (a new `NN-` folder). Promotion from
daily sketch to indexed piece is the maker's call, not the agent's.

## Imagination layer
See `imagination/SPEC.md`. `/spark` (exhale) proposes work; `/inhale` folds new
`interface.md` notes back into entities. Collisions the maker acts on get a
`spawned:` link and a Trace entry; ones they dodge age up in `charge`.
