# Vilnius Graffiti Guess

A five-round visual guessing game using archival Vilnius graffiti photographs. Guessing builds a mental map of the city through streets, architecture, and surroundings.

## Interface

Two panes: an archival photograph and an interactive map with five anonymous answer dots. Drag, scroll, or pinch to explore; Fit All restores context. Pixel landmarks mark Gedimino bokštas, Seimas, Tauro kalnas, Halės turgus, and Rotušė. Hover or tap reveals their names.

Choose one dot for an immediate reveal. Correct guesses get a bright YES; other guesses show the answer and distance. Optional sound, photo enlargement, five-round recap, and replay. No accounts or saved scores.

## Material

Five Commons photographs from 2010–2012 with published approximate camera geotags and source/license credits. OpenStreetMap road and river geometry. Built-in ImageGen landmark illustrations.

## Run

Serve the 100days repository over HTTP and open `daily-sketch/sketch-vilnius-graffiti-guess/`. The root entry opens `dist/`, which contains the authored application. ES modules and local JSON fetches require HTTP.

## Connections

Visual memory, cultural connection, archival photography, playful cartography, learning through guessing.
