# Landmark artwork

Generated with the built-in ImageGen tool. Original transparent PNG outputs are stored in the project and rendered as small pixel-style map landmarks. These are stylized illustrations, not archival photographs.

The Seimas sprite retains a faint glow from the initial generated image; the optional cleanup pass did not complete.
