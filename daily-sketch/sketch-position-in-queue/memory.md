# Position in Queue Memory

## What's working

- The generated style is working: black-first scratchboard, brutalist office,
  post-Soviet administrative space, fluorescent emptiness, and small faceless
  human scale.
- The direction should combine with the clear channel aesthetic: procedural
  layout, hard grids, technical restraint, sparse accent color, and system-like
  UI signals.

## Learning thread

- Learn how to integrate my own drawing into this workflow.
- Treat image generation as a collaborator for atmosphere and spatial grammar,
  not as the final authority.
- The next useful experiment is to draw over or into the generated page, then
  feed that drawing back as the composition/style anchor.

## Next test

Use my drawing as an input layer:

1. Make a rough hand-drawn panel, corridor, figure, or office object.
2. Scan or photograph it plainly.
3. Use image generation to extend the drawing into the brutalist office world.
4. Reassemble the result inside the clear channel frame: deterministic grid,
   captions, gutters, state labels, and one accent.
