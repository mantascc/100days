# sketch-retro-primitives

## idea
Animated primitive shapes inspired by a retro neon screen aesthetic: fuzzy glow, old CRT texture, mint outlines, warm orange cores.

## tags
canvas, primitives, neon, retro, crt, grid

## stack
vanilla · canvas · CSS

## motion
Four fixed 200×200 px tiles: circle, square, triangle, ellipse. Each shape drifts with slight analog wobble, chromatic echo, scanlines, grain, and soft bloom.
