# sketch-field-notes

## idea
Field notes on a house style that was not designed. A moodboard-shaped mini-system that sits between design-system documentation and a mood collection — every claim carries a sketch citation, every rule is followed by the exception where it stopped holding.

## tags
design-system, reference, moodboard, emergent, computational-aesthetics, meta

## stack
vanilla · IBM Plex Mono + Instrument Serif · CSS custom properties · tiny live canvases

## motion
Small live canvases sampling recurring moves from the sketchbook — proximity link mesh, glyph density ramp, summed sines drift, per-cell threshold — each cited to the sketches that spawned it. Ambient, quiet, physics-driven.

## why not another design system
Sketches 69-clear-channel and 70-clear-channel-2 formalize the visual language as a system. They read as architected. This one reframes the same material as *observed*: recurring plumage rather than declared rules, tensions kept open instead of resolved, exceptions where the rule broke and it worked.
