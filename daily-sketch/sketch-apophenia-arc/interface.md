# sketch-apophenia-arc

## idea
Conrad's apophenic arc as an instrument: Trema → Apophany → Anastrophe → Un-anastrophe. Same field of dots; one boolean (`valveOpen`) flips sublime to paranoid.

## tags
apophenia, instrument, agents, particles, valve, address, paranoid, sublime

## stack
vanilla · IBM Plex Mono · canvas

## motion
Swell → snap → spiral → deflate. Trema is durative drift on summed-sines (no figure). Apophany is a punctual link bloom — the constellation resolves for ~220ms. Anastrophe is recursive — cursor becomes the convergence point, intensity feeds itself. Un-anastrophe deflates and reveals the mechanism in a HUD ("it was never about you"), then loops back to Trema.

`?v=open` forces the valve open; `?v=welded` welds it shut; otherwise it's a coin flip per load. The welded version never leaves Anastrophe.
