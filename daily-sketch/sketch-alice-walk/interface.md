# sketch-alice-walk

## idea
A curiosity pattern rendered as an ever-relocating agent: LOCK → SAMPLE → SATURATE → LEAP. She never arrives — she leaps when local information gain flattens. One dial (dwell depth) sets the band between skimming and fixating.

## tags
generative, interactive, agent, curiosity, canvas, computational-minimalism

## stack
vanilla · JetBrains Mono · canvas/CSS

## motion
Continuous animation loop: a small agent drifts with heavy-tailed micro-steps toward an attractor (LOCK/SAMPLE). A saturation meter fills as gain diminishes; when it hits threshold, the agent LEAPS to a fresh attractor. The fading trail records recent path; the attractor pulses; a flash ring marks each leap. One live slider (`dwell depth`) shifts the run between dissipation and fixation.
