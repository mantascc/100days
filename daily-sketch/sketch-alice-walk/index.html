SUMMARY

Search has a target and stops. The Alice walk has no terminal state — it is a limit cycle, not a path. She locks onto a gradient, samples it with small heavy-tailed steps, and when the place goes quiet she leaps to the next. Curiosity as the consent to fall, repeated forever.

The counterintuitive part is the trigger. The leap does not fire when she finds something — it fires when she stops finding. Local information gain flattens, the gradient dies, she goes. A place ends not when it is understood but when it goes silent.

THE ONE PARAMETER

That leaves exactly one real dial — dwell depth: how flat the gain must get before she leaps. It has a narrow healthy band. Curiosity is that band, between skimming and fixating.

too shallowskims everything, inherits nothing — her shadow, dissipation.
in bandforages: samples deeply enough to learn, leaves before it stales.
too deepstops relocating, becomes fixation — a different character entirely.

WHY IT MATTERS

Render an agent's exploration as an Alice walk and a human can read, at a glance, whether it is foraging or merely dissipating. The walk makes curiosity legible. It is an observability primitive — the interface-epistemology thesis with a moving part.

THE CODE

// Alice walk — a curiosity pattern (not a search)
// signature: LOCK -> SAMPLE -> SATURATE -> LEAP
// the leap fires when information gain flattens, not on arrival.

let dwellDepth = 6;      // the one real dial (skim <-> fixate)
let sat = 0, gain = 1, mode = 'LOCK';

function step(){
  const d = dist(pos, attractor);

  if (d < 220){                // SAMPLE: milling near the gradient
    mode  = 'SAMPLE';
    sat  += gain;              // accumulate what she is learning
    gain *= 0.985;            // diminishing returns — gain flattens
  }

  if (sat >= dwellDepth){      // SATURATE: the place has gone quiet
    mode = 'LEAP';
    attractor = spawn();      // relocate — curiosity never terminates
    sat = 0; gain = 1;        // reset novelty
    return leap(toward(attractor), levy(140)); // heavy-tailed jump
  }

  // LOCK / SAMPLE: biased, heavy-tailed micro-steps
  const bias = d < 220 ? 0.35 : 0.85;
  const ang  = toward(attractor) * bias + noise();
  return leap(ang, 18 + levy(22));  // mostly small, rarely long
}

// heavy tail -> mostly small steps, occasional long leaps
function levy(s){ return s * Math.pow(1 - Math.random(), -1/1.5) - s; }
